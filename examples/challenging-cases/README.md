# Examples of challenging cases where Llemy underperformed

This directory contains examples of Llemy responses that were evaluated poorly by the users. These examples were selected to cover observed cases of fundamental factual errors, failure to locate existing map content, and fabricated or mismatched map reaction references. They illustrate misunderstanding map element types, missing available annotations, and instances where the system failed to recognise entities present under synonyms. 

The examples were selected by user low scores (1 or 2) for at least two performance metrics.

Besides user comments, we offer our interpretation of the output under **Developer comment** field.


## Information about example files

Each example file contains:

- Accessed map: what map was processed
- User query: what the user requested, redacted to remove potentially sensitive information
- Metrics: which metrics were indicated as low by users 
- User query: written feedback from a give user, redacted to remove potentially sensitive information
- Developer comment: feedback and comment of Llemy developers providing further detail and speculation about the reasons for this particular behaviour
