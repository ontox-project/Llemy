# Llemy response variability

Examples provided here illustrate variable output of Llemy from the same map (Liver Lipid Metabolism Map of the [ONTOX project](https://ontox-project.eu/), based on the same user question, one of default options suplied by Llemy (`What is the scope of this map? Give me a brief summary of the biology represented`).

System answers differ in length, content, and structure. In `Example 2` the system provides a link to some related proteins, but ont the others. In other examples, no links are provided.
